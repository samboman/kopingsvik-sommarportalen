# Kopingsvik Sommarportalen

Jag har https://kopingsvik.se. 

Har fått lite förslag och ideer. Hjälp mig ta fram en passande somrig design.

Hur kan webbplatsen generera intäkter?

Här skulle jag framför allt satsa på lokala företag och samarbeten, inte traditionella annonsnätverk.

Låg

Jag skulle göra grundläggande företagsinformation gratis. Det är viktigt för att webbplatsen ska vara heltäckande och användbar.

Betalningen ska gälla extra exponering och funktionalitet, inte möjligheten att finnas med.
